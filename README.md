# Challenge #1 - FURIA Landing Page

Bem-vindo ao repositório da **Landing Page Interativa da FURIA**, criada como parte do desafio técnico da organização. Este projeto simula uma experiência única de torcida, com mural ao vivo, placar em tempo real e integração com transmissão ao vivo.

## **Objetivo**
Criar uma landing page totalmente interativa e responsiva para representar o espírito da torcida FURIA, com:
- Simulação de partida ao vivo.
- Mural animado com mensagens dos fãs.
- Atualização automática de placar e tempo.
- Interações com emotes e mensagens especiais.
- Visual moderno e compatível com a identidade visual da FURIA.

---

## **Tecnologias Utilizadas**

- **Next.js 14** (App Router)
- **React 18**
- **TypeScript**
- **Tailwind CSS**
- **Framer Motion** (animações)
- **YouTube Embed** (como simulador de streaming ao vivo)

---

## **Funcionalidades**

### **1. Tela principal**
- Frase de impacto e chamada para ação: *"Solte o grito. Sinta a Fúria."*
- Animação com a mascote *Panterinha*.
- Botão para entrar no mural da torcida.

### **2. Transmissão ao vivo**
- Embed de um vídeo do YouTube com autoplay.
- Informações sobre o confronto atual (FURIA x M80 - ESL Pro League 21).
- Cards dos jogadores da FURIA com imagens.

### **3. Mural da Torcida**
- Simulação mensagens animadas enviadas por fãs.
- Atualização automática a cada 5 segundos com mensagens aleatórias simuladas.
- Envio de mensagens pelo usuário com destaque.

### **4. Placar ao Vivo**
- Atualização dinâmica do placar (até 12 pontos).
- Contagem regressiva de tempo por round.
- Detecção de vitória com mensagem especial.

### **5. Página Sobre**
- Informações adicionais sobre jogadores.
- Layout limpo, responsivo e adaptado para mobile.

---

## **Layout Responsivo**
O site foi desenvolvido com foco total em responsividade:
- Mobile First.
- Adaptação fluida para diferentes tamanhos de tela.
- Compatível com navegadores modernos.

---

## **Como Rodar Localmente**

```bash
# Clone o repositório
git clone https://github.com/leticiaro7/furia-landing.git
cd furia-landing

# Instale as dependências
npm install
```
# Rode o projeto localmente
npm run dev
